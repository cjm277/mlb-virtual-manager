# AI Prompts

This file logs the prompts typed into the vibe coder while building MLB Virtual Manager. Secrets and API key values are never recorded.

Each phase section includes the phase name, the prompt typed, any follow-up prompts, and one sentence on what the first prompt was missing.

## Phase 3 - Stats engine and tools

- Prompt typed: "Sweet. Let's move the chains and head to phase 3: Stats engine and tools * Key elements: plain Python functions, with no LLM involved, for: * stats as of the day before the game, using the 2025 fade; * left/right splits; * pitch arsenals; * how each batter does against each pitch type; * matchup scores; * the rotation predictor; * the opponent lineup predictor; * bullpen workload and availability; * sample-size flags. These become the agents' tools. * My recommendation: plain PydanticAI function tools instead of an MCP server. MCP adds a second process for graders to start, which is more 10-minute-rule risk, and the final project doesn't require it. * Evidence: * The rotation predictor's accuracy across every 2026 game, computed for free with no LLM. It's a great number for the report. * Unit tests for the blend math. Get after it and let me know about any issues or clarifications"
- Follow-up prompt: "Before we move to phase 4, the assignment specifies that we want this tool to be something that I could give to a human today and they could use. In that vein, let's try to extend this app's functionality to the 2027 MLB season, for which the schedule should already be known (it was published July 2026). Of course that will be a bit different and present it's own complications, so don't change anything about our fundamental approach. Off the top of my head: we'll need to use historical season stats exclusively because the 2027 season hasn't happened yet. For now, we'll have to assume rosters are the same in 2027 as they were at the end of 2026. Free agency will change that, but we can't predict that so let's not. Anything else you need me to specify to add this functionality? If so, let me know. Either way, get after it. Once that's built into the functionality and your understanding of our project approach, let me know if you think we're ready to move on to phase 4."
- What was lacking after the first: The first prompt only covered past (2026) games, which a real manager can't use today; the follow-up added the published 2027 schedule, planned with full-2026 stats and end-of-2026 rosters.
