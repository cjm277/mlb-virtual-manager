# Evidence

Proof from real runs that backs up the numbers and claims in `report.html`.

| Folder | What goes in it |
|---|---|
| `screenshots/` | App screenshots: good runs, edits, safety defenses catching something |
| `logs/` | Audit trails and token counts from real agent runs |
| `tests/` | Saved output from safety tests, backtests, and data spot-checks |

Name files `phaseN_short-description.ext` so each one is easy to trace to the report.
