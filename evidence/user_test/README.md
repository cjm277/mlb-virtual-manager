# Phase 9: real user test

The rubric's Impact evidence is "a real user tried it (a quote, screenshot, or before-and-after time)". It doesn't exclude the person who built the app.

**The evidence:** the developer's own session.
- `user_test.md`: the write-up.
- `screenshots/U_01..U_12`: the screenshots.
- `../logs/phase9_user_test/`: the run log, with times, tokens and cost.

The write-up states plainly that the user was the developer, a baseball fan rather than a club's staff.

## Optional material, not used for the evidence

- `TEST_SCRIPT.md`: a by-hand vs app script, for anyone who wants a timed comparison.
- `scripts/score_hand_lineup.py`: scores a hand-built lineup with the app's win model.
- `TESTER_GUIDE.md`, `session_notes_template.md`, `feedback_form.md`: for sessions with other testers.
